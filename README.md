# Anima Forge

運行於手機上的 AI 角色扮演聊天介面。

本專案基於 [Vali-98/ChatterUI](https://github.com/Vali-98/ChatterUI)，是一個嘗試加入視覺小說風格與沉浸式角色互動體驗的 Fork 版本。

**Repository:** https://github.com/baroquee2-dev/AnimaForge

目前仍在開發中。

---

## English

An AI role-playing chat interface for mobile devices.

This project is based on [ChatterUI](https://github.com/Vali-98/ChatterUI), developed by Vali-98. It is a fork exploring a visual novel-inspired and more immersive approach to AI character interaction.

**Repository:** https://github.com/baroquee2-dev/AnimaForge

Currently a work in progress.
