# ChatterUI Visual Novel Mode

運行於手機上的 AI 角色扮演聊天介面。

本專案的主要程式架構源自 **Vali-98 開發的 ChatterUI**，這裡是一個以視覺小說風格與沉浸式角色互動為方向的實驗性 Fork 版本。

目前仍在開發與測試階段，主要修改內容尚未正式上傳。

**Work in Progress.**

---

## English

An AI role-playing chat interface designed for mobile devices.

This project is based on the original **ChatterUI developed by Vali-98** and is an experimental fork exploring a more visual novel-inspired and immersive approach to AI character interaction.

The project is still under development and testing. The main modifications have not yet been uploaded.

**Work in Progress.**
